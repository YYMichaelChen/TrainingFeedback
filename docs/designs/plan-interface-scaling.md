日期：2026-10-08（Asia/Shanghai）。这是用户要求的原生 PySide6 实现映射。
持久产品规则由[产品规范 §4.1.1](../development-plan.md#411-plan-editor-sizing-and-interface-scale)

GitHub Release，承接版本为 [0.8.14](../releases/0.8.14/design.md)。

## 原生实现

| 用户规格 | PySide6 对应 |
| --- | --- |
| 唯一 `--u`、rem、系统 DPI | `sizing.u()` 从应用基准字体获取逻辑字号；Qt 自行处理物理 DPI；QSS 仅在框架边界生成 px |
| 原生默认边距、图标 | `UnitStyle` 提供字体相对的 layout/icon/indicator metrics；显式尺寸使用 `bind_units` 随缩放更新 |
| 80%–200%、步长 10% | `InterfaceScale`、设置页滑杆与跟随系统/自定义；本机 `QSettings` 界面文件与训练根无关 |
| clamp 与比例布局 | 按可用屏幕计算弹窗初始尺寸；三栏按 18%/剩余空间/24% 和相对上下限分配 |
| 80u、56u 响应断点 | `PlanPanes` 使用弹窗宽度；指导抽屉、顶部动作胶囊复用原选择和内容，不重建处方 |
| 固定头部与底部 | 外层 `QVBoxLayout`，基本信息、中栏、指导各自滚动；外层没有滚动容器 |
| 自适应参数 | `AdaptiveFields` 的标签与控件组成单元；参数最多四列、基本信息最多两列 |
| 多行文本可拉高 | `ResizableTextEdit` 至少三行，拖动下沿竖向手柄；外部区域限高并滚动 |
| 比例组次表 | `RelativeTable` 保留完整逐组备注，增加组次和行删除入口；>8 行限高；控件自然宽度可提高 28u 下限 |
| 指导与图片 | `PlanGuidance` 的锚点条常驻；比例图、完整图注与分组指导在同一滚动区域；图片可放大 |

QSS 原生 API 需要逻辑像素整数，因此生成后的样式含 `px` 是边界转换，
并非独立设计常量。保留的 `1px` 均为分隔线。0 表示无边距或无最小限制。
未新增 CSS、WebView、Electron、依赖或训练数据库字段。

## 数据与证据

保存仍通过现有计划服务与确认流程。逐组备注、未知数值、休息适用性、
动作组、精确内容版本和用户原文继续保留；缩放设置不属于个人训练事实。
其它原生页面的既有显式几何尺寸同步接入 `u`，以避免字号变大而间距仍固定。
