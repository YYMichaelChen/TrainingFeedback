## 原生实现

| 用户规格 | PySide6 对应 |
| --- | --- |
| 唯一 `--u`、rem、系统 DPI | 正文基准约 14 逻辑像素；字号独立于屏幕分辨率与窗口大小，`sizing.u()` 从应用字体取值；Qt 处理物理 DPI |
| 4K 屏幕上的 2K 默认窗口 | `initial_window_size` 按完整屏幕逻辑宽高的 2/3 得到 16:9 客户区，在物理 3840×2160 屏幕上为物理 2560×1440；其他比例按较小轴容纳，且不超过可用屏幕的 96% |
| 原生默认边距、图标 | `UnitStyle` 提供字体相对的 layout/icon/indicator metrics；显式尺寸使用 `bind_units` 随缩放更新 |
| 80%–200%、步长 10% | `InterfaceScale`、设置页滑杆与跟随系统/自定义；本机 `QSettings` 界面文件与训练根无关 |
| clamp 与比例布局 | 编辑弹窗以默认主窗口区域为上限，按 85%/88% 初始化；三栏按 17%/剩余空间/28% 和相对上下限分配 |
| 96u、64u 响应断点 | `PlanPanes` 使用栏区实际宽度；指导栏扩大至 22u–30u，抽屉、动作胶囊复用原选择和内容 |
| 固定头部与底部 | 外层 `QVBoxLayout`，基本信息、中栏、指导各自滚动；外层没有滚动容器 |
| 自适应参数 | `AdaptiveFields` 的标签与控件组成单元；参数最多四列、基本信息最多两列 |
| 多行文本可拉高 | `ResizableTextEdit` 至少三行，拖动下沿竖向手柄；外部区域限高并滚动 |
| 紧凑逐组表 | `RelativeTable` 保留完整逐组备注、组序与行删除入口；短字段按各列的相对下限、表头和控件自然宽度分配，余宽给备注；>8 行限高；窄窗口只在表内横向滚动 |
| 指导与图片 | `PlanGuidance` 的锚点条常驻；比例图、完整图注与分组指导在同一滚动区域；图片可放大 |
| 紧凑主页面 | 训练开始/历史双卡片在 66u 以下堆叠；计划、训练、批量操作栏使用 `ActionBar` 自动换行；设置内容限宽 |
| 独立动作框 | `CardList` 与 `FramedItemDelegate` 给图库、动作多选、组成员、计划导航及动作下拉条目绘制独立圆角框；测量宽度与绘制宽度一致，悬停不改变几何 |

QSS 原生 API 需要逻辑像素整数，因此生成后的样式含 `px` 是边界转换，
并非独立设计常量。保留的 `1px` 均为分隔线。0 表示无边距或无最小限制。
未新增 CSS、WebView、Electron、依赖或训练数据库字段。
