# 0.8.15 紧凑窗口与独立动作框

日期：2026-10-09（Asia/Shanghai）。用户要求缩小默认字号、重新安排页面结构，
修复动作条目悬停遮挡，并澄清其 3840×2160 屏幕上的默认窗口应为
2560×1440、16:9，随后授权“提交推送并release”。

- 主窗口默认占完整屏幕宽高的 2/3，并保持 16:9；其他比例按较小轴容纳，
  可用屏幕优先。窗口尺寸独立于自定义字号，Qt 处理物理 DPI。
- 正文基准约 16→14 逻辑像素，收紧标题、按钮、侧栏及页边距。
- 开始训练/历史双卡片在窄窗口上下排列，操作栏自动换行；设置内容限宽。
- 动作图库、动作多选、组成员、计划版本和动作下拉使用独立圆角框，
  按当前字体及宽度测量条目；悬停、选中与键盘焦点不挤压相邻文字。
- 编辑弹窗以默认窗口区域为上限，指导栏和三栏断点使用实际栏区宽度。

应用 `0.8.15`，schema `24`、catalog `070-illustrated-3`、contract `4` 不变。
保存、事务、原文和未知数值语义保持；不访问真实数据或旧训练数据库。
