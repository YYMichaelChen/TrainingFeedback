# 0.8.17 计划排序与默认编辑

日期：2026-10-09（Asia/Shanghai）。用户反馈拖动后动作暂时消失及卡顿，并要求
默认右侧显示编辑表单，随后明确要求提交、推送并发布 GitHub Release。

- 拖动由计划文档处理，避免 Qt 在拖动结束后再次删除来源行。
- 排序只移动既有导航节点并重编号，保留编辑控件；关闭指导抽屉时不读取指导内容或图片。
- 默认选中动作即显示处方编辑，取消只读摘要和“编辑所选项”入口，底部统一保存整个草稿。
- 独立动作切换保留未完成输入，动作组与成员切换先校验并归入未保存文档，避免副本覆盖。

应用 `0.8.17`；schema `24`、catalog `070-illustrated-3`、contract `4` 不变。
持久规则由[产品规范](../../development-plan.md)
拥有；[源码记录](../../history/0.8.16/plan-editor-follow-up-2026-10-09.md)说明改动，
[开发记录](../../history/0.8.17/development.md)承接候选和分发身份。
