# 0.8.14 计划界面与本机缩放

日期：2026-10-08（Asia/Shanghai）。用户要求计划编辑界面改用相对尺寸、
响应三栏布局和本机缩放，随后明确授权“提交推送并release”。

应用补丁版本 `0.8.14`；schema `24`、catalog `070-illustrated-3`、
plan/evidence contract `4` 不变，不新增迁移或兼容承诺。

- 单一字体相对单位，Qt 处理系统 DPI，80%–200% 本机缩放与快捷键立即生效。
- 计划弹窗按自身宽度切换三栏、指导抽屉、顶部动作胶囊；头部与底部操作固定。
- 基本信息折叠、多行文本可拉高、参数自动换列；组次表使用比例列宽、行删除、
  原始备注与局部滚动；指导、完整图注和常驻锚点独立显示。
- 原保存确认、事务、动作组、未知数值和用户原文语义保留。
