# 0.8.20 计划添加与保存分离、计划文件模板

日期：2026-10-18（Asia/Shanghai）。用户明确要求将本次两项改动提交、推送并 release。

- 计划编辑时独立提供“添加到计划”，只接收内嵌动作／组并加入未保存的左侧列表，
  不弹出整份计划保存确认。“保存草稿”仍是独立操作，可保存未完成输入。
- “导入计划文件”旁增加“新建计划文件”，在内存中显示只读当前 JSON v4 模板。
  用户必须另存到自己选择的位置后自行编辑；关闭、取消和反复打开不积累文件。
  成功另存后请求系统打开副本，保留原有严格导入、确认和启用边界。

应用升为 `0.8.20`；schema `25`、内部编辑格式 `1`、catalog `070-illustrated-3`、
外部 plan/evidence contract `4` 均不变。没有具体启动失败风险，应用测试和人工测试
均为 0 项；构建和 GitHub 分发不扩大检查范围。只分发本次可识别的干净安装包。
