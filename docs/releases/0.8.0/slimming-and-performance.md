## 优化及同机结果

无图草稿不再占图片检查缓存；有图缓存按最近使用淘汰单项。浏览仍读取当前字节
hash，文件变更/删除即时失效；选择、训练和审核动作继续重新检查。
保存前的名字/家族检查共享一次动作内的读取；取得 SQLite writer lock 后再读取
一次并复核，不跨事务或跨根缓存。profile 中整库 list 从 6 次降为 2 次。

| 数据集 / 操作 | 原 p50 / p95 ms | 本轮 p50 / p95 ms |
| --- | ---: | ---: |
| 36 内置 / 热浏览 | 73.92 / 76.76 | 73.22 / 76.70 |
| 36 内置 / 保存 | 47.93 / 50.06 | 20.12 / 22.07 |
| 36 内置 + 100 草稿 / 热浏览 | 844.06 / 853.58 | 105.95 / 117.80 |
| 大样本 / 保存 | 97.92 / 101.96 | 39.86 / 43.90 |
| 大样本 / 冷图片检查 | 840.27 / 853.81 | 847.93 / 853.28 |
| 大样本 / 重开上下文 | 121.70 / 125.35 | 122.36 / 127.19 |

大样本热浏览 p95 下降 **86.2%**，保存下降 **56.9%**，达到热点下降 30% 目标。
冷图片检查目标未达：仍需完整解码 36 张大图，不能用缓存热测替换这个边界。
重开耗时未改善，本轮保留完整资源校验；不会声称所有关键路径都已达标。
客户端首次显示有无反馈、主线程 200 ms 停顿、真实输入刷新、非空历史与大备份
仍 **not run**，由精确候选的开发者手动验收补齐。P4 响应验收尚未完成。
