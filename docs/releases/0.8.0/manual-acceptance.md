# 0.8.0 开发者手动验收

全部项目当前为 **not run**。本表用于精确候选，候选路径/hash 在
[版本记录](../../history/0.8.0/development.md) 的构建证据中确认后再操作。
不得使用真实个人根或旧项目数据库。工具不能代替开发者操作客户端。

## 隔离与开始

使用本机专用普通 Windows 测试账户，避免同 AppId 注册覆盖正在使用的安装。
这仍是本地验收，不是独立机器公开验收。建立一个验收父目录，例如
`E:\TrainingFeedback-080-Acceptance`；程序、profile、根 A/B 和外部备份各用独立子目录。
不要把程序装到数据根内。所有数据和训练结果都标记为合成。

在该测试账户的 PowerShell 7 中设置独立 locator 环境，再从同一窗口启动
候选安装器、已安装 EXE 和卸载器；不要用桌面/控制面板启动带删除的数据测试，
否则进程可能没有继承独立 profile。路径由操作者填写，不复制真实 locator。

```powershell
$acceptanceDirectory = 'E:\TrainingFeedback-080-Acceptance'
$env:LOCALAPPDATA = Join-Path $acceptanceDirectory 'profile'
New-Item -ItemType Directory -Path $env:LOCALAPPDATA -Force | Out-Null
Start-Process -FilePath 'E:\Github\TrainingFeedback\dist\installer\TrainingFeedback-0.8.0-Setup.exe' -Wait
```

安装器默认程序位置由 Windows 账户决定，独立 locator 不改变该产品规则。
先在目录页选择验收父目录下含中文/空格的独立程序目录；不自动启动应用。
安装后从上述窗口手动运行实际安装的 EXE，数据根选 A 的空目录。
遇到错误先记录原文和操作，不删除恢复记录或更换 profile 来伪造重试通过。

## 优先执行的流程

| ID | 操作与期望 | 状态 |
| --- | --- | --- |
| M01 | 自定义中文/空格程序目录安装；安装完成，receipt 出现，EXE/卸载入口与快捷方式指向当前程序。取消新根选择不创建根/locator。 | not run |
| M02 | 建空根 A，内置 36 动作及图片齐全；新建/编辑草稿，保留空白、原文和未知值。重启两次后仍相同。建 B、切 A/B，各自数据隔离。 | not run |
| M03 | 同候选原位重装；再换新程序目录重装，只有当前有效快捷方式，原程序卸载完成。关闭客户端的根/locator 字节保持一致。 | not run |
| M04 | 卸载默认不勾删除；取消卸载、取消二次确认均不改根/locator。完成默认卸载后根/locator 保留，重装可重开。 | not run |
| M05 | 在同一 profile 中关闭应用，卸载勾删除；显示的完整路径必须是合成当前根 B。确认后 B 和该 locator 删除，A 与根外备份保持原样。 | not run |
| M06 | 客户端仍打开时卸载：删除选项被禁用且有原因，可只卸程序。无 locator、未来/损坏根、链接、权限失败也安全禁用；不自行扫描其它目录。 | not run |
| M07 | 专门合成根测试中断删除/重试：错误列出剩余目录和恢复记录，部分根拒绝打开；重装后重试只接受原剩余对象。不要在唯一副本上做故障注入。 | not run |
| M08 | 代表性计划启用、开始、暂停、退出、重开、继续、完成；冻结内容/原文不变，实际值空白不推断完成。备份包含记录和图片。 | not run |

非法路径（盘符根、系统目录、根及其父子目录、无关非空目录）必须拒绝；
换程序位置失败应明确提示重装，数据仍保留。静默卸载永远保留数据。
若专门测试静默流程，由开发者手动运行并记录，不以代码测试代替。

## 响应验收与记录

实际操作启动、切根、首次页面、图片/搜索刷新、保存、非空历史和大备份。
对关键路径同机同数据规模记录 20 次 p50/p95、是否显示进度/可取消和最长
无反馈停顿；**常用交互无反馈停顿 >200 ms 的门槛尚未验证**。
首次冷图片检查的服务层 p95 仍约 853 ms，须重点观察客户端反馈与可用性，
不能只凭热浏览结果判通过。未达标应记录 fail，继续修复，不把 not run 改为 pass。

回报可先给 M01–M05：每项 pass/fail、测试账户、实际程序/根/profile 路径、
错误原文或截图、是否残留文件。失败时保留候选身份和现场；其余项目仍 not run。
完整验收需要全部受影响项的实际记录。内容审核、个人转换、W4、正式/公开发布
不由这个表自动成立。
