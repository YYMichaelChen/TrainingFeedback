## 3. 记录方法：重复次数和起止点

每类操作先做2次预热，再做20次正式操作。材料中的“人工计时.csv”已分好8类、
每类22行，前两行标为warmup（预热），其余为sample（正式样本）。
不用自行计算统计值；可以只反馈录屏文件和每段对应的操作/重复序号，我根据原始

开始秒数、结束秒数、结果和备注。保留失败样本，不能用一次成功替换失败。

录屏中鼠标点击/按键提交是计时起点，下面每步列出终点。等待提示、卡片逐渐出现
也要录下来。一次整页完成耗时不等于主线程停顿；低帧率或只有主观“流畅”反馈

## 4. 启动和动作库首次显示：两类共用22次启动

1. 从第2步的PowerShell命令启动。录下按回车到“训练”页面内容显示完整且能
   点击“设置”的区间，这一段归startup（启动）；不把文件选择/人工等待混入。
2. 点击“动作库”。从点击导航开始，到136张卡片的文字、数量和检查状态完成，
   记录为library（动作库首次显示）。滚动检查内置卡片缩略图有无异常，记录期间
   是逐渐显示还是整个窗口没有反馈。无图自定义草稿保持草稿是预期。
3. 关闭程序，等待进程退出和PowerShell返回，再开始下一轮。

每轮重启保证这是该进程第一次进入动作库；已打开过页面的热切换不能替代首次
显示。预期窗口能打开、逐卡显示有反馈，无错误和无限“检查中”。失败时反馈该轮
序号、等待过程、卡片状态和录屏。关闭/重新输入命令的人工时间不计入耗时。
