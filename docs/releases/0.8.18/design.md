# 0.8.18 计划编辑列宽与滚动条

日期：2026-10-10（Asia/Shanghai）。用户反馈计划编辑表格列过宽、水平滚动条
不明显，并明确要求提交、推送和 GitHub Release。

- 单列控件不再按比例撑宽所有列；短字段使用各自的最小宽度，备注接收余宽。
- 窄窗口在表格内部水平滚动，上方表单按可用宽度换行；表格预留滚动条高度。
- 水平滚动条具有有色轨道、深色滑块和悬停／按下强调。
- 剂量及成员按钮按自然宽度换行；“组次”改为“第几组”，“退出后休息秒”改为
  “动作结束后休息（秒）”，动作组使用自己的休息文案。

应用 `0.8.18`；schema `24`、catalog `070-illustrated-3`、contract `4` 不变。
