# image2.5 新增动作示意图提示词（21–36）

本文件收录第 21–36 项新增动作的完整示意图提示词。每个 `text` 代码块均可单独复制使用，无需另加通用前缀；每个动作生成一张含 2–3 幅阶段图的正方形图片。提示词完成不代表图片已经生成、关联或通过审核；在合格图片实际交付前，动作指导仍保持“暂无动作示意图”。第 01–20 项见[上一批提示词](exercise-image2.5-prompts-01-20.md)。

## 使用约定

- **画面要求**：PNG 格式，1:1 正方形比例。
- **系列视觉**：成年白人女性、健美身材、饱满且比例协调的胸部、金色高马尾、黑色长袖长裤连体瑜伽服（躯干不透明，四肢半透明网纱）、紫色垫具、白底写实教材插画。第32条单独采用普通运动体型与全身不透明运动服，以该条独立提示词为准。若生成工具支持参考图，可在首张满意后沿用该图作为人物与风格参考，提高跨图一致性。
- **布局**：站姿、坐姿、高跪姿和半跪姿从左到右；卧姿、四点跪撑从上到下。流程箭头连接阶段，关节旁的短箭头表示局部运动。
- **动作依据**：依据 [权威目录](../initial-exercises-and-plan.md) 和仓库中的 `src/training_feedback/data/seed/catalog.py` 编写；本文件覆盖范围以本批索引为准。插画中的深度不是用户必须达到的幅度，不附加训练组数、次数或保持秒数。
- **左右侧**：单侧动作先用同一侧讲清完整过程，以短注说明换侧，避免一张图内左右变化导致误读。
- **审核重点**：先遮住文字，逐幅核对实际支撑面、悬空手脚的间隙、头颈方向、左右肢体归属及阶段变化，再核对着装、标签和箭头。后脑/额头必须接触指定支撑，头发接触不能代替；不同动作的全脚掌、脚跟、前脚掌、脚外缘或脚背支撑按各条独立要求判断。提示词不代表实际图像已通过审核。
- **文件组织**：每批提示词新建一份独立 Markdown 文件，完整复制本节“使用约定”并只列出本文件动作索引；每个提示词都必须包含完整视觉与动作要求，不依赖其他文件的通用前缀。

## 本批说明

- **接触点通审补充**：本批各动作分别核对头颈、足部接触与阶段变化；第26条保留用户明确的仅脚跟接触，第27/28条支撑脚仍全脚掌踩稳。第23条保留实际换腿的画面左右对应。34–36区分额头支撑、膝部接触与脚部悬空，不能混画。
- 第 21–36 项为新增的抬腿、坐姿核心、臀桥、四点跪撑和俯卧髋伸变式。
- **2026-09-21 修订**：每个代码块均完整内置服装分区、固定支撑点、三个静态姿势与成图核对要求。复制时应复制整个代码块，不能只复制动作段。
- **着装判定**：除第32条整件运动服均不透明外，其余条目胸、腹、腰、背、臀、裆完整不透明，双臂和双腿为可辨认的黑色半透明细网纱；长袖到手腕、长裤到脚踝，手脚裸露；腰部连续相连。三幅都要满足，不以其中一幅正确代替整张合格。
- **阶段判定**：一幅只画一个姿势。第 24/25 项把“屈膝回中”单独画为中幅，左右两幅展示两种伸展，完整循环按短注回到中幅；阶段图不是叠影。
- **参考图使用**：若已有合格人物图，可同时作为外观参考，并注明“仅沿用人物、服装和画风，动作以本条要求为准”。先确认参考图的袖长、裤长和材质分区均正确。第32条只参考人物和画风，服装始终按该条的全身不透明运动服重新绘制。
- **修改不合格图**：向工具提供具体错误及对应面板，例如“仅修正中幅左脚落垫，使其完全悬空并与垫面留出空隙”；服装错误要指出部位，并要求三幅同步修正。修改后仍须重查动作、肢体与着装，不把保留其他内容视为已经验证。
- **审核顺序**：先查各幅服装覆盖与材质，再查支撑点和悬空间隙、左右侧与膝角、阶段路径，最后查文字与排版。本轮只优化文本，未生成或验收图片。

## 21 仰卧直腿开合

```text
生成一张健身教学动作示意图，PNG格式，1:1正方形，纯白背景、柔和均匀光线、淡灰接触阴影，精细写实教材插画。人物为同一位成年白人女性，健美匀称，胸部饱满且与身材比例协调，金色高马尾，神态专注，赤脚。

【服装硬性要求】
穿同一件黑色长袖长裤连体瑜伽服，上衣与裤子在腰部连续相连，没有露腰缝隙。圆领贴近锁骨，前胸、腹部、腰侧、整个背部、臀部及裆部均为实心黑色不透明运动面料，完整遮盖，不透肤、不镂空。双臂从肩部袖缝到手腕、双腿从臀下与裆部包覆区的下缘到脚踝，均为连续的黑色半透明细密弹力网纱；四肢肤色与肌肉轮廓隔着黑色薄纱隐约可见，仍能辨认网纱覆盖，不能画成裸露皮肤，也不能画成实心黑袖或实心黑裤。网眼细密均匀，无大孔或花纹。袖口恰好止于手腕，裤脚恰好止于脚踝；双手和双脚裸露。各幅服装剪裁、接缝、透明度完全一致。
服装排除项：两件式运动内衣配裤子、露脐、无袖、短袖、短裤、七分裤、全身不透明紧身衣、全身透视装、躯干透明、蕾丝、大孔渔网、丝袜连脚、手套、鞋袜、亮面皮革或乳胶。

【构图与固定部位】
标题“仰卧直腿开合”。三幅从上到下排列，足端侧前45°略俯视，能看清双腿开合方向及两侧髋部。每幅一张相同紫色瑜伽垫。全程头、肩、骨盆和双臂着垫，双掌放体侧；躯干与垫的位置不变，双脚始终悬空。

【接触点与头颈】
全程后脑勺自然落在紫色瑜伽垫上，脸朝天花板，下巴自然，头不抬向胸口或膝盖，也不昂下巴后仰；肩背有支撑。颈部保留自然曲线，不强行压平，也不靠头颈主动顶地。马尾向头侧铺开，不垫在后脑下托高头部，不能用头发碰垫代替后脑接触。双掌在体侧朝下接触垫面；双膝以下直到双脚全程悬空，足底不接触任何物体。打开时允许双脚随开合改变空间高度，但两腿整体仍朝上，不下放成贴地横叉。

【三个静态阶段】
上幅“并腿举起”：仰卧，双腿并拢举向上方、接近竖直，双膝自然伸展而不锁死；两条腿轮廓可区分。
中幅“向两侧打开”：双腿从两侧髋部对称向外打开成适度V形，两腿整体仍保持朝上举起，膝角与上幅相同；打开方向横跨身体左右，不是向足端地面下降。骨盆仍平稳着垫。
下幅“沿原路合拢”：恢复上幅并腿举起的位置，双脚仍在高处，头肩和骨盆不抬起。

【路径与短注】
阶段间用向下紫色箭头连接，中幅髋旁两条短弧箭头指向左右外侧，下幅箭头指向中线。短注只写“骨盆稳定”“呼气合拢”；页脚“结束时先并腿，再屈膝放脚”。
不要画成向地面落腿、剪刀交叉、横叉贴地、卷腹抬头、骨盆离垫或膝盖反张。

【本动作验图】
后脑与骨盆不动，双脚始终悬空，两腿在上方打开再合拢。

【成图核对】
每幅仅一名人物，是同一模特的不同阶段；每幅恰好两臂两手、两腿两脚，四肢从肩或髋连续可追踪，允许自然前后重叠，但远侧手脚仍可辨认。头部、手脚及垫具完整入画，保留边缘空白；使用固定机位和统一缩放，不用镜像翻转、裁切、透明人体、残影或额外肢体表达动作。箭头位于空白处，不盖住身体或接触点。服装材质差异在每幅都清晰可辨；动作结构与着装优先，装饰从简。只写本提示词指定的标题、阶段标签和短注，黑色清晰无衬线字；不加组数、次数、保持秒数、品牌、水印、额外人物或未指定道具。
```

标题“俯卧双腿屈腿抬腿”，副标题“双侧同时·较低抬起”。三幅从上到下排列。相机从足端沿身体纵轴朝头部看，向人物右侧偏约40°，向下俯视约30°，形成明确的斜后方三分之四视角；头在画面左上、膝在右下，垫面长轴斜穿画面，不横平地画成纯侧面。必须同时看清两侧大腿、两膝及各自膝下垫面，两条小腿和两只脚轮廓分开，近侧腿不能完全挡住远侧膝。三幅机位、人物朝向和缩放完全相同；若提供旧图，只沿用人物、服装与画风，重建机位和腿姿。
每幅一张相同紫色瑜伽垫，额头下放一块薄紫色折叠毛巾。双臂弯曲放头部两侧，前臂和双手着垫。额头、骨盆前侧与下腹全程保持支撑，头胸不抬。双膝约90°，两脚始终悬空、彼此分开，不脚掌相贴。

【脚掌朝向与足部结构】
三幅统一采用自然中立踝位，足的长轴与自身小腿约成直角，不刻意绷脚、勾脚或扭踝。第一、三幅小腿朝上时，两脚尖都朝身体足端、远离头部，脚底朝上、脚背朝垫面；不能把脚尖竖直延长成小腿的尖端，也不能把脚底翻到应为脚背的一面。第三幅直接沿用第一幅正确的双脚姿态。
每只脚都由自身小腿经脚踝连续连到脚跟、足弓、前掌和脚趾。左右大脚趾各在靠两腿之间的内侧，不能用同一只脚复制成两只。趾甲在脚趾背面，足弓和掌纹在脚底，不能混拼；每脚五趾，允许自然透视遮挡，不为展示全部脚趾或整块脚底而翻转脚掌。脚跟、前掌有正常厚度，脚背连续，不扁成薄片，不横折、不反接。
第二幅两脚分别保持相对各自小腿的同一中立踝位，随两条小腿同步转动；脚底、脚背的可见角度随之自然变化，不能单独绕脚踝或小腿长轴扭转。左右足各随自身腿移动，不能把一只脚固定在原位，也不能交换两脚。

【起始位：双腿平行并排】
两侧大腿分别从各自髋部向足端伸出，平行于身体纵轴，左右并排、约髋同宽；双膝在身体纵向上齐平，没有一膝前伸、一膝后缩。双膝间距与两侧髋的间距相当，内侧之间能看到一条垫面空隙。两膝都弯约90°，两条小腿分别从各自膝部朝上，两脚分开。保持两条平行的腿部路径，不夹腿、不交叉、不叠成一条腿，也不张成八字或蛙腿。斜透视可产生正常远近差，但不能改变两腿在垫面上并排的实际位置。

【接触点与头颈】
额头实际接触薄毛巾，脸朝下、鼻口留有空间，颈部随躯干自然延长；不抬脸看镜头、不用下巴支撑、不把头转到一侧。毛巾始终平放垫面，不以马尾触垫代替额头支撑。双前臂和双掌平放头旁垫面，不能用手撑起胸部。双脚在三幅都悬空，双大腿和双膝在上、下幅接触垫面；中幅两膝同时离垫，各自下面都有虽小但清楚可见的真实空隙。两侧大腿远端随膝一同离垫，不能仍平贴垫面而只抬脚；不能一膝着垫、一膝悬空。头、双前臂、骨盆前侧和下腹继续有支撑，不能用整个人物抬离垫面表示抬腿。

【三个静态阶段】
上幅“双腿髋宽准备”：按上述平行并排起始位，双大腿与双膝贴垫，两小腿朝上、两脚悬空；中立踝位，脚尖朝足端、脚底朝上、脚背朝垫面。
中幅“双大腿同步低幅抬起”：从两侧髋部同时小幅抬起两条大腿，髋至膝的轴线仅略向后上方倾斜，两膝同时稍离垫，各有一处可辨认的膝下空隙。两侧实际离垫高度一致，维持髋宽和平行，不交替、不前后错位；正常透视造成的远近大小不同不等于一高一低。双膝保持约90°，两小腿与两脚随各自大腿同步转动，小腿上端相应向头侧略倾，不强行保持竖直；两脚相对各自小腿的踝位不变，不通过加深屈膝、勾脚跟或横折前掌伪造抬腿。骨盆和下腹仍有支撑，头胸不抬。
下幅“双膝同时回垫”：双大腿和双膝同步放回起始并排位置，恢复髋宽；两小腿仍朝上、双脚仍悬空。两脚的形状、踝位与脚掌朝向均回到第一幅，不能重画成反向脚掌。

【路径与短注】
向下紫色流程箭头，两侧大腿旁的空白处各画同样短的抬落箭头，位置分别对应左右大腿，不能指向腰背或臀部。短注“双腿同步抬起”“低幅度，双膝都离垫”。本图的双侧大腿倾角与膝下间隙都较小，应明显低于单侧屈腿抬起的示意高度；同时必须画出两膝真实离垫，不能以低幅度为由省略间隙。比较的是髋至膝的倾角，不是脚的高度。
不要画成左右交替抬、单侧大腿留在垫上、双脚贴合、双膝大幅外张、只做小腿弯举、骨盆或腹部离垫、抬头挺胸或大幅腰部后弯。

【本动作验图】
先遮住文字检查：上下幅双大腿平行并排、约髋宽、双膝贴垫；中幅两侧大腿都以较小角度抬起，两膝下方各有真实且可见的空隙，不能一侧贴垫或画成单侧高抬。两条小腿和两只脚全程分开、膝角约90°不变、双脚悬空；额头与骨盆仍有支撑。若远侧膝下被遮住、只有脚变高或仅添加阴影，不能判断为合格。
