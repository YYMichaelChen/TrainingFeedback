baselines. It is not the canonical source for current runtime schemas.

Current runtime schemas live only in
[`src/training_feedback/contracts/`](../../../src/training_feedback/contracts/).
The application packages those files directly. Frozen baseline files here are
evidence and must not be rewritten to match current behavior.
