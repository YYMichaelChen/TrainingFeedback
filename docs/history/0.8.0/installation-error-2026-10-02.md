# 2026-10-02 安装目录提示失败与修复

开发者提供的截图显示：0.8.0 安装向导在目录页预填
`E:\Github\TrainingFeedback\.tmp\acceptance-075\c2\program`，前进时弹出
英文 `[Errno 2] No such file or directory`，缺少的是程序归属文件
`.training-feedback-program.json`。

**本次错误提示检查记为失败。** 截图没有安装包 SHA-256，不能确认属于哪一个
精确候选；也没有证据说明安装完成、训练数据变化或其它检查通过。
原始截图保存在 [截图证据](evidence/installation-error-2026-10-02.png)。

程序目录校验对非空目录要求归属清单及安装记录，是当前安全边界。没有这些
记录的旧目录不能直接覆盖。缺文件异常未转换为用户可理解的说明，属于提示
处理缺陷；本次修复捕获缺清单和缺安装记录，给出中文说明、具体目录和恢复
步骤，并让 Inno 显示 helper 返回的完整多行提示。

恢复步骤是取消安装、用已知旧程序自己的卸载器仅卸载程序并保留数据，然后
重开安装器。对其它文件夹保留原文件，使用新的空程序目录。不会补造归属清单、
自动删除旧目录、读取旧训练数据库或增加历史版本兼容承诺。若同一 Windows
账户仍登记旧安装，单改新目录不能跳过旧程序安全检查。

代码级检查在隔离合成目录验证两种缺文件错误、中文步骤和程序文件不变。
同一 release-0.8.0 minor scope 的受影响 26 项通过，累计 100 unique cases；
其它未受影响结果复用。安装包由修复后的干净源码重建，精确身份另记。
完整中文弹窗、旧卸载器操作、新目录实际安装及客户端检查仍待开发者手动
复验；agent 没有运行安装器或客户端。
