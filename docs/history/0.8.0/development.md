# 0.8.0 Development

Application 0.8.0, schema23, catalog070-illustrated-3, plan/evidence contract3.
Only the application identity changes; schema layout, content bytes and external
wire schema remain unchanged. Internal installation/cleanup manifests are private
helper protocols. No formal/public release or personal-data transition is declared.

Installation adds program-directory selection, path/ownership verification,
exact obsolete-payload cleanup and explicit relocation. Uninstall keeps data by
default; interactive deletion covers only the verified locator's current root,
with confirmation, Windows handle binding and interruption recovery.
Implementation and actual development checks are in the
[implementation record](../../releases/0.8.0/implementation.md).

Unused historical upgrade and reset writers were retired, with pending/unknown
states refused unchanged. 36 byte-identical image copies were removed from seed;
the canonical catalog, hashes and reproducible output remain intact. Hot browse
and override save improved in synthetic service measurements, while cold decode
and actual client response remain incomplete. See the
[slimming and performance evidence](../../releases/0.8.0/slimming-and-performance.md).
