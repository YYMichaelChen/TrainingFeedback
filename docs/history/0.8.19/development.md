## 分发后源码修正：添加动作与保存计划分开（2026-10-18）

用户反馈选完动作必须点“保存草稿”才能加入左侧列表，随后又弹出整份计划保存确认。
原因是内嵌添加表单的按钮被隐藏，父级只提供保存入口，连续执行完成添加和计划保存。

`ui/group_plan_page.py` 的底部新增独立“添加到计划”按钮，仅在添加动作／组期间显示，
只接收当前表单、更新未保存的左侧列表并继续编辑，不调用计划预览或持久化。
添加期间默认按钮指向“添加到计划”，防止默认回车落到整份草稿保存。
“保存草稿”仍单独可用，明确点击后可连同未完成节点保存；“放弃添加”行为保留。
产品规范同步说明两种操作的边界。

本次为局部交互修正，无具体应用启动失败风险；应用测试 0 项，人工测试 0 项，
不执行客户端自动操作或功能回归。受影响文件 Ruff、文档链接／身份和 Git 差异静态检查均通过。
应用 `0.8.19`、schema `25`、catalog `070-illustrated-3`、外部 contract `4` 及
编辑文档格式 `1` 均不变。未构建或分发新安装包，上述已发布候选不包含本次修正，
既有候选证据不作为本次界面行为通过的证明。局部修正不新开 Planscope，INDEX 保持无活动版本。
