# 全动作 image2.5 示意图提示词

包含先前 **20 个动作的提示词**。每节代码块内是一段完整提示词，可单独复制使用，无需另加通用前缀。每个动作生成一张含 2–3 幅阶段图的正方形图片。第20项已纳入种子动作目录，训练计划另行编排。2026-09-17 分两批新增的 16 个动作暂未包含在本提示词集内，指导中保持“暂无动作示意图”。

## 使用约定

- **画面要求**：PNG 格式，1:1 正方形比例。
- **系列视觉**：成年白人女性、健美身材、饱满且比例协调的胸部、金色高马尾、黑色长袖长裤连体瑜伽服（躯干不透明，四肢半透明网纱）、紫色垫具、白底写实教材插画。若生成工具支持参考图，可在首张满意后沿用该图作为人物与风格参考，提高跨图一致性。
- **布局**：站姿、坐姿、高跪姿和半跪姿从左到右；卧姿、四点跪撑从上到下。流程箭头连接阶段，关节旁的短箭头表示局部运动。
- **动作范围**：依据 [权威目录](initial-exercises-and-plan.md) 和现有 `src/training_feedback/data/seed/catalog.py` 指导编写；第07项为静态臀桥举臂进阶版，第14项为深度站立前屈，第19项为后坐前移加跪姿俯卧撑，第20项为臀坐脚跟的跪姿双臂前伸拉伸。目录后来新增的16项暂未制作图片提示词，插画中的深度不是用户必须达到的幅度，不附加训练组数、次数或保持秒数。
- **左右侧**：单侧动作先用同一侧讲清完整过程，以短注说明换侧，避免一张图内左右变化导致误读。
- **审核重点**：生成后核对人体结构、接触点、对侧手脚、箭头方向与下列动作约束。提示词不代表实际图像已通过审核。

## 01 臀桥

```text
生成一张用于健身教学的动作示意图，PNG格式，画面比例为1:1的正方形。采用精细写实的健身教材插画风格，纯白背景、柔和均匀光线、淡灰接触阴影。人物为同一位成年、美丽的白人女性，健美匀称且肌肉线条自然，胸部饱满、轮廓圆润自然，与健美身材比例协调，金色头发扎高马尾。穿无标志的纯黑色长袖长裤连体瑜伽服：躯干部位采用不透明面料，胸部、臀部及裆部完整覆盖；双臂从肩部至手腕、双腿从大腿至脚踝采用黑色半透明细网纱材质，网纱下可自然透出四肢肤色与肌肉轮廓，袖口止于手腕、裤脚止于脚踝。赤脚，神态专注自然。画面标题为“臀桥”。采用严格侧面略偏前的视角，使双腿轮廓能区分；3 幅阶段图从上到下排列，用向下的紫色箭头连接，标注“1 准备”“2 抬髋”“3 还原”。第1幅：仰卧在紫色瑜伽垫上，双膝弯曲，双脚与髋同宽平踩垫面，双臂自然放在身体两侧，头肩着垫。第2幅：双脚压地，臀部抬起，肩、髋、膝大致形成一条斜直线，骨盆保持水平，双膝朝向脚尖；用贴近髋部的短上弧箭头表示抬髋。第3幅：缓慢放低臀部，回到第1幅的仰卧屈膝位。加短标签“呼气抬髋”“吸气还原”“脚掌压实”。重点画清髋部升降、脚掌始终着地及头肩支撑，不画腰部过度反弓、颈部顶地或膝盖内扣。所有阶段保持人物身份、身体比例、服装、器材、视角与缩放一致，阶段变化只来自规定动作。每幅完整显示头部、双手、双脚及必要器材，边缘留白，肢体之间轮廓清晰；紫色流程箭头放在阶段图间的空白处，短运动箭头放在对应关节旁，均不遮挡身体。画面只使用指定中文标题、简短阶段标签和必要提示，字体清晰；不加品牌、水印、装饰背景、额外人物、额外肢体或未指定器械，确保关节方向、支撑点与动作结构合理。
```
