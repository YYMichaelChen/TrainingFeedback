# Initial Exercises And Plan Proposal

Status: approved catalog scope; bundled guidance remains unreviewed and plan remains draft\
Last updated: 2026-09-21

This document defines the first catalog candidates and the initial plan used to
develop and validate the application. It is not a medical assessment and its
example doses are not automatically treated as a confirmed prescription.

The [development plan](development-plan.md) defines review, activation, history,
and release requirements. This document owns seed names, body areas, and proposed
doses; it does not certify that bundled guidance has passed expert review.

**Current development content:** Section 10 defines the current family mapping,
movement clarifications and outstanding illustration/content deliverables. Sections
1–9 retain the still-valid catalog definitions and proposed doses carried forward
into 0.7.0. The [current product rules](development-plan.md#12-current-catalog-and-group-contract)
govern use. Catalog/workflow implementation is delivered; revised bridge content
and actual illustrations remain pending, so this is not a ready personal plan.

Under [development-data policy](development-plan.md#133-development-content-and-personal-data-transition),
every intended development addition/revision to actions, guidance, aliases, families
and illustrations must enter owned source and the packaged catalog. New roots must
see the full latest library without an old database or manual import. A local-only
override is not delivered content. Deliberately reconcile useful development edits
before retiring roots; never automatically harvest personal content. User-authorized
transfer to personal data is deferred until the user decides development is ready.
Synthetic reviews/training are not part of that personal baseline.

## 3. Guidance Completion Requirements

Every launch-catalog exercise must have the following content before the first
usable release:

- purpose;
- primary and secondary body areas;
- starting position;
- ordered movement steps;
- breathing;
- tempo or hold guidance;
- intended sensations;
- common compensations;
- stop criteria;
- regression;
- progression;
- equipment;
- applicability and cautions;
- image or explicit image-missing state.

The old project may be consulted manually, but the completed guidance belongs
to this repository's own seed data and must not be loaded from the old runtime.

Current implementation: `data/seed/catalog.py` owns exercise-specific bundled
guidance for all 36 catalog exercises. Standing forward fold is v3, the five
previously revised items remain v2/v3 as recorded below, and the 20-action audit
update adds v2/v3 content revisions; the remaining items are v1. Each has a stable bundled exercise key and content
identity/version, blank review facts,
and an explicit missing-image state. New roots receive these drafts directly;
existing roots receive selected drafts only through the local preview and
acceptance action. Required-field validation still does not constitute content
review. Record external review evidence and user confirmation only when they
occur; review and selection as the in-use version are separate. Bundled metadata
must never represent an expert review,
user approval, or confirmed exercise dose.

User-supplied illustration files are not bundled catalog facts. When the expected
files exist in a selected data root, the application may explicitly associate
them by stable exercise key, deriving new local unreviewed revisions from the
current in-use guidance while preserving all earlier revisions.
The sixteen fourth- and fifth-batch exercises currently have no supplied
illustrations; their guidance retains the explicit missing-image state. The existing image mapping
continues to reference the 20 supplied files.

### Fifth-Batch Movement Definitions And Technique References

These ten exercises follow the user's movement definitions, including the
confirmed diagonal direction: with the right leg moving, start outside the
left supporting leg and extend toward the right rear/upward direction.
Guidance adds the following interpretation and counting conventions:

| Exercise | Movement and control boundary | Counting |
| --- | --- | --- |
| 臀桥单侧踢腿 | Keep bridge height while one leg extends forward/upward, its knee slightly above the supporting knee, then bends and returns. Arms remain by the sides; keep the pelvis level. | One extension and return is 1 rep for the **moving** leg. |
| 单腿臀桥 | Keep one near-straight leg raised about 60° **to the floor** as a comfortable reference. The planted leg raises and lowers the pelvis, with the free foot remaining off the floor. | One pelvic lift and return is 1 rep for the **supporting** leg. |
| 直腿后踢 | From quadruped, extend one leg backward with a soft knee, lift only within neutral lumbar control, then lower and bring the knee under the hip. | One extension/lift and return is 1 rep for the moving leg. |
| 驴踢 | Keep the moving knee bent about 90° while lifting the thigh backward/upward, then return the knee under the hip. | One full lift and return is 1 rep for the moving leg. |
| 驴踢脉冲 | Enter a controlled donkey-kick high position, lower slightly, then perform small raises/lowers just below that upper boundary. The knee stays suspended and bent about 90°. | Each small raise and lower is 1 pulse/rep for the moving leg. Initial entry and final return do not add reps. |
| 斜向驴踢 | Right leg stays softly bent, crosses behind the left lower leg to its outer side, extends toward the right rear/upward direction, then returns along the same path. Left is mirrored; keep the pelvis facing down. | One cross-side start → own-side extension → cross-side return is 1 rep for the moving leg. |
| 消防栓 | Keep the knee bent about 90° and raise the thigh to the side, then return under the hip. Do not rotate the pelvis to gain height. | One lateral raise and return is 1 rep for the moving leg. |
| 俯卧直腿抬腿 | Lie prone with legs slightly apart, head supported, knees softly extended; raise one thigh a small distance and lower it while the pelvis stays on the mat. | One thigh lift and return is 1 rep for the moving leg. |
| 俯卧屈腿抬腿 | Lie prone, thighs slightly apart, knees bent about 90°; raise one thigh while the other stays down, then lower with the knee angle maintained. | One thigh lift and return is 1 rep for the moving leg, not a lower-leg curl. |
| 俯卧双腿屈腿抬腿 | Same prone bent-knee setup, but lift/lower both thighs simultaneously through a small range. Keep the lower abdomen and front pelvis supported; avoid lumbar extension to gain height. | One simultaneous lift and return is **1 total rep**, `per_side=false`. |

All unilateral entries use `reps`, `per_side=true`; N per side means N left
and N right, following the side convention above. Pulses use the existing reps
unit, not a new dose type. Set counts, numeric doses and rest are determined in a
separately confirmed plan, not inferred from these instructions.

For the five quadruped entries, the user-specified starting position has hands
under shoulders, knees under hips, thighs approximately vertical, elbows
naturally extended, and knees/toe tips grounded. Once the moving leg lifts, its
knee and toe leave the mat; both hands and the opposite knee/toe remain as support.
Near-straight and softly bent knees are distinct from the approximately 90°
donkey-kick/fire-hydrant knees. Hip height is limited by lumbar and pelvic
control, not by an instruction to kick as high as possible. For prone entries,
raise the thigh rather than merely curling the lower leg; the bilateral version
uses a particularly small controlled range and can regress to unilateral work.

References checked 2026-09-17:

- [ACE quadruped bent-knee hip extensions](https://www.acefitness.org/resources/everyone/exercise-library/270/quadruped-bent-knee-hip-extensions/)
  supports neutral-spine bracing and hip-extension range limited by lumbar
  control. Its starting foot position differs; toe-tip contact here follows the user.
- [Physitrack prone hip extension with bent knee](https://us.physitrack.com/home-exercise-video/prone-hip-extension-with-bent-knee-%28adaptive%29)
  supports a bent-knee unilateral lift with the hips flat on the floor, a brief
  hold and controlled lowering. Bilateral lifting is the user's requested variant.
- [Rehab Hero single leg glute bridge](https://www.rehabhero.ca/exercise/single-leg-glute-bridge)
  supports planted-leg drive and abdominal bracing with a neutral spine. Its
  free-leg position differs; the approximately 60° raised leg here is the user's variant.

These are references for general technique cues, not reviews of all ten exact
variations. Diagonal routing, bridge kicks, pulse counting, and the adapted
Chinese guidance are application-authored elaborations of the user's request;
review fields remain blank. No source dose is adopted as a user prescription.

### Fourth-Batch Movement Definitions

The user's clarification for `卷腹伸腿` and all three variations is:
“就是坐姿后倾，腹部收紧，双手支撑”. All four keep the buttocks seated,
the upper body leaning back, both hands supporting on the floor beside/behind
the hips, and the abdomen engaged. Their shared posture is not a supine crunch;
the bicycle variation does not add elbow-to-knee trunk rotation.

- `仰卧直腿开合`: lie supine with head/shoulders resting, both straight legs
  raised toward vertical; open to the sides and close while keeping them raised.
  One open-and-close cycle is one repetition (`per_side=false`).
- `卷腹伸腿`: keep both feet together, extend both legs forward, then return
  to bent knees; one extension-and-return is one repetition (`per_side=false`).
- `卷腹踩单车`: alternate the legs in a bicycle motion. One leg extending
  and returning counts once for that leg; N per side means N left-leg and N
  right-leg extensions (2N total, `per_side=true`).
- `卷腹并腿左右伸`: keep the legs together, extend them toward one side, and
  return to bent knees before extending toward the other side. One paired
  extension-and-return counts once for that direction; N per side means N
  leftward and N rightward extensions (2N total, `per_side=true`).
- `卷腹并腿分腿交替伸`: extend the paired legs forward and return to bent knees,
  then separate and extend the left leg leftward and right leg rightward
  simultaneously into a comfortable V, and return to bent knees together.
  This entire sequence counts once (`per_side=false`).
- `臀桥腿开合`: the user confirmed “脚跟原位，膝盖开合”. Hold a controlled
  bridge with both heels stationary on the floor, open the knees outward and
  return inward to their starting position. One open-and-close cycle is one
  repetition (`per_side=false`); the heels do not slide sideways.

These Chinese instructions and counting conventions are application-authored
bundled drafts. They are not expert review or an automatic prescription.

### Third-Batch Movement Definitions And Sources

- `扶墙提踵`: bilateral heel raises on level ground with stable wall/rail support.
  Raising and lowering both heels together counts as one repetition; `per_side`
  is false. A single-leg or step-edge version is a later variation.
  [NHS strength exercises](https://www.nhs.uk/live-well/exercise/strength-exercises/).
- `鸟狗式`: quadruped opposite-arm/leg extension with a stable trunk and pelvis.
  One extension and return counts as one repetition on the extending-leg side;
  N per side means N left-leg and N right-leg extensions (2N total).
  [ACE Bird-dog](https://www.acefitness.org/resources/everyone/exercise-library/14/bird-dog/).
- `跪姿冲肩` (corrected 2026-09-16): begin with hips behind the knees and arms
  reaching forward, move forward into one bent-knee push-up, press up, then rock
  back. Knees remain supported throughout. The knee-to-hip ray and forward ground
  ray form an obtuse angle at the start; this is not a prescribed knee joint angle.
  One full cycle counts as one repetition; `per_side` is false. The combination
  follows the user's definition. The lowering/pressing cues draw on
  [ACE bent-knee push-up](https://www.acefitness.org/resources/everyone/exercise-library/13/bent-knee-push-up/).
  Keep the old name only as a lookup alias, not an instruction to keep elbows
  straight throughout; do not automatically alias the ambiguous `俯卧冲肩`.

Sources checked 2026-09-15. The Chinese instructions, counting conventions,
and example pacing are application-authored adaptations. They are not claims
that these sources reviewed this application or approved an individual plan.


## 8. 2026-09-16 To 2026-09-17 Catalog Revisions And Addition

The user requested that the illustration clarifications become actual catalog
guidance. Keep exercise IDs, stable exercise keys and historical revisions.
The two kneeling corrections below explicitly update their display names.

- `静态臀桥` v2: keep hip height while both arms rise from the sides to approximately
  90 degrees to the ground and return; exhale while raising, inhale while lowering,
  with gentle abdominal/lower-rib movement. The dose unit remains seconds;
  arms-at-sides static holding remains a regression.
- `站立体前屈` v3: deep standing forward fold, allowing the torso to approach the
  thighs within individual capacity. Bent knees and higher support remain options.
  “180 degrees” is not a required joint angle; do not force range or target ligament
  lengthening. [YogaEasy guidance](https://www.yogaeasy.com/artikel/standing-forward-bend).
  Hands may touch the floor or gently hold the backs of the ankles, without pulling
  the torso down. Gentle sensations can occur in the back of the thigh or calf;
  neither location is mandatory or identifies a particular tissue. Keep the whole
  foot grounded and avoid shifting forward to pursue stronger Achilles-area aching.
  Reduce depth or bend the knees if uncomfortable; stop if discomfort persists.
  [Forward-bend hand positions and muscle groups](https://www.yogajournal.com/poses/types/forward-bends/pose-week-standing-forward-bend/?scope=anon),
  [AAOS stretching principles](https://orthoinfo.org/staying-healthy/safe-exercise/).
  Persistent pain or Achilles-area morning stiffness, tenderness or pain during
  walking/heel raises warrants assessment rather than deeper stretching.
  [RNOH Achilles information](https://www.rnoh.nhs.uk/patients-and-visitors/patient-information-guides/achilles-tendinopathy).
- `坐姿90/90髋转换` v2: specify one leg in front and the other folded to the side/back,
  with both legs returning through the centre; preserve the bilateral workflow.
- `仰卧4字臀部拉伸` v2: keep the crossed ankle touching the support thigh while both
  hands hold the support thigh's back; lower the support foot before uncrossing.
- `跪姿冲肩` v2 replaces the straight-arm-only definition: hips back at the start,
  controlled forward movement into one knee push-up, press up, then hips back.
  Name and lookup alias change as above; equipment stays mat and dose stays reps.
- Item 20, `跪姿双臂前伸拉伸` v2, replaces the seated upper-back stretch: kneel,
  sit hips toward heels, fold forward and slide both arms forward with palms down,
  hold gently, then walk hands back and rise. Hips stay near heels during the hold,
  rather than high over the knees. Primary 背部, secondary 肩部; equipment changes
  from chair to mat; static hold remains measured in seconds.
  [Mayo Clinic Mindful Movements, child's pose](https://sharedfiles.mayoclinic.org/bedside/ope/GNT-20421908.html).
  This does not diagnose or promise to release fascial adhesions.

The two legacy keys `main.kneeling-straight-arm-lean` and

descriptions. Explicit metadata synchronization updates their names/equipment and

### 10.3 Continuous-Group Examples

The primary format example is **直腿后踢 1 次 → 消防栓 1 次**, repeated for an
explicitly chosen positive number of rounds. Both use quadruped support.
For a same-side-then-switch example: first-side kick → first-side hydrant →
opposite-side kick → opposite-side hydrant makes one round. The first side,
round count, transition, side-switch/round rest and every dose must be present
in the plan. N such rounds mean N kick reps and N hydrant reps on each side;
do not count the entire sequence as one rep of either catalog action.

A bridge sequence can combine repeated bridge reps, a timed static bridge and
bridge knee-opening reps. Each retains its own unit, guidance and illustration.
The UI shows per-round doses and never adds seconds to reps as one numeric total.
Prone raises followed by a quadruped hydrant require an explicit body-position
transition, so they are not the same-position example.

These are representation examples. The existing 13-action proposal and actual
user plans are not automatically regrouped or assigned new doses. A revised
proposal/real plan is a new draft with an explicit complete prescription and
normal confirmation; its content must be supplied before it is advertised as
a ready-to-train 0.7.0 plan.

Per-round sets, side order and rest boundaries must stay explicit. Actual work on
one side never supplies the other's dose; format fixtures are synthetic, not
approved prescriptions. Removal/restoration follows the development plan's current
lifecycle rules, preserving frozen facts and independent variant identities;
it cannot supply missing artwork, review or a substitute movement.
